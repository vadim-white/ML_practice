# ML_practice

Сборник проектов по машинному обучению, NLP, DL и работе с LLM.

## 📁 Проекты

### 🔹 [1488-solution](./1488-solution/)
**RAG-система с подавлением галлюцинаций**  
Решение для **Yandex Cup 2025**. Пайплайн обеспечивает строгую консистентность ответов на семантически одинаковые вопросы и отсекает выдумки: если точных данных нет, модель отвечает `"Не знаю"`. Реализовано через кэширование эмбеддингов, векторный поиск, мульти-кандидатную генерацию и LLM-оценку уверенности.

### 🔹 [mini-rlhf-reward-model](./mini-rlhf-reward-model/)
**Исследование Reward Model для RLHF**  
Полный цикл разработки модели предпочтений на датасете Anthropic HH-RLHF. Включает кэширование эмбеддингов, аугментацию пар, сравнение Logistic Regression и PyTorch MLP, а также честную валидацию на независимом тесте. Выявлено, что простые линейные признаки (`diff embeddings`) обобщаются лучше сложных нейросетей при слабом сигнале в данных.

---
**Стек:** Python, PyTorch, Scikit-learn, llama.cpp, HuggingFace Datasets, SentenceTransformers, RAG-архитектуры.
